# FFTIC Randomizer 0.6.2

Randomize **Final Fantasy Tactics: The Ivalice Chronicles — Enhanced** with a
Windows app. Choose a seed, select what changes, generate a mod, and launch it
through Reloaded-II.

## Download and play

Download **fftic-randomizer-0.6.2-windows-x64.zip** from **Assets** below.
Extract it and open **FFTIC Randomizer.exe**. Python, FF16Tools, and the converter
runtime are included.

1. Set up [Reloaded-II](https://github.com/Reloaded-Project/Reloaded-II/releases)
   and [FFTIC Mod Loader 1.7.5 or newer](https://github.com/Nenkai/fftivc.utility.modloader/releases).
2. Select the game folder containing **FFT_enhanced.exe** in the randomizer.
3. Choose a seed and settings, then click **Generate randomizer mod**.
4. Click **Open output** and install the **fftivc.randomizer.seed** folder in
   Reloaded-II's **Mods** folder, or drag **randomizer-mod.zip** onto Reloaded-II.
5. Enable the randomizer and loader for Enhanced, then click **Launch Application**.

Read the [installation and first-run guide](https://github.com/Pyre-Flies/FFTIC-Randomizer/blob/v0.6.2/docs/INSTALL.md)
and [settings guide](https://github.com/Pyre-Flies/FFTIC-Randomizer/blob/v0.6.2/docs/SETTINGS.md).
Both guides are also included in the Windows ZIP.

## Included in this release

- **Shuffle** and **Full redistribution** ability modes.
- Shared changes to ordinary and unique jobs, including jobs in the opening battle.
- Optional changes to equipment, monsters, encounters, formations, rewards,
  shops, job progression, and music.
- Hover descriptions, keyboard help, and a resizable, scrollable settings window.
- Seed reports so you can inspect randomized abilities before playing.

Use one active seed and keep a separate save slot. This version checks for the
supported Enhanced build; Classic is not supported. Startup and loader checks
have passed, but a full campaign and every ability combination have not been
playtested.
