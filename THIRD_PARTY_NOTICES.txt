FF16Tools by Nenkai
https://github.com/Nenkai/FF16Tools
Version 1.13.3 is used for game archive extraction and Nex table conversion.
The Windows executable distribution bundles the official converter, layouts,
native dependencies and .NET runtime. The Linux distribution builds the pinned
FF16Tools source with a native GDeflate adapter and lowercase layout aliases;
its extraction and NXD conversion code is otherwise unchanged. Their notices are
included under licenses/. FF16Tools is not required to run a generated mod.
Its MIT license grants redistribution with the copyright/license notice.
The source-only ZIP excludes downloaded vendor dependencies; its build script
retrieves/verifies the required inputs. No original game files are bundled.

Bundled executable runtimes
Python 3.13 (Python Software Foundation), Tcl/Tk, PyInstaller bootloader,
Microsoft .NET 9, and the converter's NuGet/native dependencies retain their
full upstream copyright and license texts under licenses/ in the executable
and portable distribution. Build receipts identify the exact versions/hashes.

This project's own managed startup bridge and guarded native runtime DLL are
included with their complete source, build scripts and source/DLL hash receipt.
